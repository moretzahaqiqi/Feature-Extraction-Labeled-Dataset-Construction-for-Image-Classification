# Feature-Extraction-Labeled-Dataset-Construction-for-Image-Classification
🧠 کاربرد این رویکرد:
این کد برای آماده‌سازی داده‌های تصویری قبل از آموزش مدل‌های یادگیری ماشین (مانند SVM، Random Forest، KNN) طراحی شده است. ویژگی‌های استخراج شده به عنوان ورودی این مدل‌ها استفاده می‌شوند.

یه پکیج کامله قشنگ 16 ساعت سرش من وقت گذاشتم بعد جونم برات بگه که فکر همه جاش رو کردم 6420 تا بعد داره بعد از این کد مکمل اون کد قبلیه و نکته مهم  اینه که یه لیبل این کدینگ هم باید انجام بدی تهش این خیلی باحال بود برام گفتم برای شما هم بزارمش این یکیی از بمبست باز کنای پردازش تصویر و یه دقت بالا بهتون میده
